# Musical Instruments — Feature Table

**Tested concepts:** Belvero, Kasten-zither
**Distractor concepts:** Veldhorn, Tambic Drum

Feature roles: **T** = tested (in questions), **P** = padding (control/repeat only), **D** = distractor concept feature

Both tested instruments are plucked string instruments. Tested features (body shape → sound character) are intentionally linked — a coherent pair.
